# Office task chair (nisu)

This model was downloaded from [OpenGameArt's Office Chair page](https://opengameart.org/content/office-chair-1)
and is attributed to **nisu**. The page marks the upload as **CC0 1.0** and
links to the original public-domain model at 3dmodelscc0.com. It includes an
FBX model plus base-color, normal, roughness, metallic and height textures.

Use `manifest.json` to verify the local files before packaging. The application
must load this copy locally; no runtime request to OpenGameArt is required.
