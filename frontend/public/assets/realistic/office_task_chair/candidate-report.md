# Candidate review: 3DAssets.dev task chair

**Status: not bundled.** The [Downtown Office Interiors task chair](https://3dassets.dev/assets/downtown-office-interiors-task-chair-upholstered-f2c77dc7)
is technically attractive: local GLB delivery, metre units, a tensioned mesh
back, lumbar slider, height-adjustable T arms and five-star castors. The pack
claims CC0 1.0 and a compact GLB, so it would be easy for a Three.js adapter to
consume.

It is not accepted for this production pack because the publisher discloses
that all 106 models were generated with Claude Fable 5.1. The current asset
policy asks for a traceable, non-AI source rather than unverified generated
geometry. No file was downloaded and no runtime dependency was added.
