# 回归测试设计

1. 读取需求、变化范围和已确认的验收条件。
2. 按需读取 `references/checklist.md`，提出正例、反例、边界和兼容性样例。
3. 每个样例注明输入、预期、对应风险和执行方法。
4. 工具权限允许时，在独立工作区新增测试；执行只能通过项目配置和真实沙箱。
5. 依赖缺失、沙箱不可用或未执行，必须保持未验证状态。
6. 把失败的真实输出反馈给负责开发的成员，不为达到某个协作轮数而停止。

本Skill没有脚本和自动依赖安装；不授予网络或宿主机命令执行权限。
