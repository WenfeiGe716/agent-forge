- 自定义协议指声明式 JSON/HTTP，可配置认证头、请求模板、响应路径及工具映射；不包括任意 SDK、任意签名代码或非 HTTP 传输。

- 本次升级前已使用 SQLite 在线备份保留 `.local/forge-before-design-center.db`。原账号、加密供应商和现有团队未重置。

接口采用独立的设计版本、证据评测和运行快照模块；设计期的编辑与生成不能直接调用运行期权限接口。这一边界指导了实现和负向验证，而不是只在界面添加“待审核”文案。
