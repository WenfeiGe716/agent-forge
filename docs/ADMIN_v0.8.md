# v0.8 管理员说明

本文件面向部署与维护人员，不作为日常办公主界面的常驻提示。

## 安装与启动边界

`bash start.sh` 自动检查 `.venv`，缺失时调用 `scripts/install-offline.sh`；首次创建 `.local/config.json`，包含数据库路径、初始随机管理员密码、随机供应商加密密钥和沙箱令牌。此文件权限0600，目录0700，不随交付包分发。管理员密码仅首次终端显示；不要分享终端截图或将本地配置加入版本库。

离线 Python 包沿用此前版本从已安装发行包重打包的27个wheel，不是上游新下载的原始发行包。许可证、SHA256和来源见 `offline/MANIFEST.json`。包适用于Linux x86_64/CPython3.13及兼容系统库，不可在ARM/macOS/Windows或其他Python版本强装。其他平台从受信任源安装 `backend/requirements-core.txt`，并另行验证执行环境。

代码执行需要Docker与gVisor/runsc。已有相应运行时及Docker访问权限时，启动器可检查/构建便利镜像并启动受令牌保护的broker；缺少运行时则只报告，不使用sudo、不安装系统级软件、不降级到不受限执行。Docker镜像、浏览器、操作系统和模型权重不包含在离线包。

独立broker的部署仍由管理员设置 `SANDBOX_URL`、`SANDBOX_TOKEN` 和一致的数据目录。启动器不覆盖自定义服务地址。`/readiness`需要令牌；它检查Docker运行时和可用镜像，不把HTTP健康等同于容器可执行性或安全认证。

运行中的任务继续使用创建时的不可变模型/供应商/Skill快照。重启不会主动清空数据库、替换加密密钥或重置供应商。无法确认外部调用结果时仍按已有规则转人工，而非盲目重复执行。

## 升级

从旧版本升级，应先处理在途任务、停止旧服务，备份数据库、工作副本和加密密钥，并在独立目录验证。不要对进行中的工作流热替换代码。新增就绪记录复用既有配置表；本版仍不是完整的数据库迁移/回滚管理器。

不要同时启动多个运行器管理同一数据库。启动器检测端口冲突，不关闭不属于它的已有服务。结束启动器会请求其子进程退出，不控制独立部署的其他服务。

## 供应商接入

支持已有OpenAI Chat Completions兼容协议与Anthropic Messages协议，不代表原生兼容所有厂商专用鉴权。模型目录仅取一个有界响应页，目录不能证明工具能力；目录不可用时仍可手工填模型ID。外部服务必须HTTPS，内网服务检查实际解析地址；不会关闭TLS验证。

连接探测需要用户点击确认，正常成功发送2次模型请求：调用受限校验工具、传回工具结果并获取确认。校验工具只返回随机nonce，不执行代码。失败不保存半套供应商配置，也不自动重试付费调用。成功提交的相同幂等请求返回已有结果。已开始但结果未知的请求不自动重放；页面刷新后重新点连接属于新的显式操作，可能再产生测试费用。

API Key加密存储，不放入普通审计事件、返回值、URL或浏览器本地存储。原有提供商修改、模型参数修改、停用仍通过管理页面进行；连接检查结论绑定提供商修订及模型版本，修改后不冒用旧检查。

## 内置Skill信任范围

只有 `backend/forge/builtin_skills/manifest.json` 中本版本列出的文本包可自动初始化。它们来自本项目、没有脚本、文件摘要逐项校验，通过后标记审核来源 `builtin:0.8.0`，不同于声称管理员逐项人工批准。没有供应链签名或外部安全认证。

现有同名自定义、草稿、撤销、停用或不同内容版本不被覆盖或重新批准。已有成员的非空Skill绑定保留。第三方Skill仍通过人工审核；原有命令权限、项目授权、审批和沙箱限制不改变。

## 网络与演示隔离

正式默认构建只包含生产模块，不包含Preview、SuitePreview、previewV07工厂，静态目录不提供旧workbench-preview入口。开发者显式 `--with-preview` 构建会生成带标识的开发预览；不得把它当成实际服务发布。正常启动强制关闭验证模式，不启动脚本化模型。

需要局域网访问时，以HTTPS反向代理保护登录和配置；设置正确允许来源与 `SECURE_COOKIE`。不要把本地未加TLS的登录服务直接暴露到公网。
