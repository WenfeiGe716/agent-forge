日期：2026-09-10。范围是现有 macOS 客户端的任务界面，不是新建模型任务或改变执行权限。

## 展示与交互

- 任务看板、办公室任务状态按钮、新任务创建成功后均可进入专用任务工作区。
- 左侧只列任务，右侧先显示当前阶段、负责人、真实状态和下一步；不从模型调用次数推算百分比。
- 内容分为“进度 / 待我处理 / 成果 / 执行记录”。有成果的任务默认进入成果页；需审批的任务突出待办。
- 进度展示实际分工、交接依赖与阶段结果；完整契约和技术回执默认折叠。
- 计划审批说明负责人、交付物、依赖、批准或拒绝的后果；最终验收明确不自动合并、推送或部署原项目。
- 安装工具和执行权限使用原有专用审批台账，直接嵌入当前任务；普通问题不能替代权限审批。后端通用回答入口也拒绝此类请求。
- 审批针对冻结摘要，提交后显示“等待执行器应用”；防重复点击、跨任务串数据和旧响应覆盖。只读账号不能审批。
- 成果页展示真实下载地址、代码差异预览、验收命令及退出结果、独立审查和人工验收。失败、未验证和通过分别呈现。
- 测试/审查按真实轮次选取，新的执行轮次不会借用旧轮的通过结果。只读讨论不显示虚构代码测试。
- 执行记录只显示当前任务最近 250 条事件，明确窗口限制，提供完整会话与追溯入口。
