# Agent Forge v0.9.0 — 人物与办公家具精修

日期：2026-09-09。基于 v0.8.1 完整源码。此次聚焦默认人物、工位家具、表面着色和细节观察，不增加或替换业务编排规则。

画面中的屏幕编辑器线条、胸牌等是装饰几何，不是正在编写代码或任务结果的证据。人物检查图中的姿态由测试输入设置，没有创建真实会议或模型调用。

### 渲染路径

动态网格支持ANGLE实例化，复用几何和实例变换，避免每帧逐顶点CPU烘焙；不支持时使用真实非实例化后备路径。细小标记和边饰限制几何开销，不以增加无效三角形作为精致度。实例化与后备路径均在实际Chromium中检查了绘制及WebGL错误。

这是自研WebGL渲染器与原创程序化关节资产。它不是Three.js，也不是完整HDR环境贴图、完整PBR贴图/骨骼资产系统。此次没有下载人物模型或替换为商业角色资产。

### 没有改变的产品边界

- 默认首页仍为登录；登录后零供应商也进入办公室。多个供应商和逐Agent独立配置不变。
- 任务、消息、来访、领导起身、多人会议与空闲抢占沿用原状态来源，没有加入随机业务交互。
- 新版本不在正式页面加入“示例散会/同事来访/重置示例”等测试按钮。
- 目标、决策、Skill、会话与行动项没有被展示动画替代。
- 外部GLB仍是受限的静态会话预览；不能让任意导入模型自动获得本轮默认人物的服装、坐姿或骨骼动作。
- 细节镜头为检查视图，不锁住任务或人物；正在走动的Agent不会为了截图停止业务。返回办公区恢复完整场景。

## 3. 性能和未验收边界

本环境为Chromium/ANGLE SwiftShader软件GPU，视口1600×1000；没有硬件GPU。本次增加几何和光照细节，不能承诺在所有设备上同时提升帧率。均衡和节能各10秒的实际采样见 `visual-browser-results.json` 的 `samples`，本次末轮独占浏览器测试分别记录17帧/10.0002秒（均衡约1.70fps）与26帧/10.0002秒（节能约2.60fps）。这属于短时观察，不是性能验收门槛。当前软件渲染仍明显偏慢；正式发布前需要在目标GPU、成员数、城市密度和分辨率下复验。

浏览器继续遵守现有管理策略，不修改DNS、网络/TLS或URL导航限制。测试通过 `page.set_content` 加载实际产物，经既有受限HTTP桥接访问真实API。未将其宣称为普通地址栏访问、原生Cookie/TLS、SSE自动恢复或浏览器下载验收。

本轮未验证真实供应商LLM开发能力、Docker/gVisor、Temporal/PostgreSQL整栈、长时间运行、压力、HA或生产安全；也未实现贴图资产库、任意GLB骨骼动画、完整动态人物避碰及跨客户端帧级同步。

离线包沿用此前已安装发行包重新打包的27个wheel，保留来源/许可证/哈希，不是本轮从上游下载的原始wheel。适用Linux x86_64/CPython3.13及兼容系统库。不分发字体、用户数据库、登录密码或加密密钥。

## 4. 使用与复验

正式入口不变：

```bash
bash start.sh
# 浏览器访问 http://127.0.0.1:8787 ，登录后选择成员。
```

进入办公室后：选择成员 → “外观” → “查看人物细节”；右下角可选精细/均衡/节能；“返回办公区”恢复完整场景。

```bash
cd frontend
npm ci --offline --ignore-scripts --no-audit --no-fund
npm run build
npm run check
cd ..
PYTHONPATH=backend .venv/bin/python -m pytest backend/tests -q
node tests/visual/models.test.mjs
node tests/visual/behavior.test.mjs
node tests/visual/etiquette.test.mjs
node tests/visual/meetings.test.mjs
node tests/visual/city.test.mjs
```

浏览器专项：`tests/e2e/v09_visual_acceptance.py`，需要独立测试副本启动8797端口API、Playwright、Chromium和DISPLAY。它会使用该测试副本的管理员账号并暂时关闭空闲演绎，禁止指向团队真实部署。

纯资产检查：`tests/e2e/v09_asset_render.py`，可选环境变量 `FORGE_BASELINE_ZIP` 指向v0.8.1归档以重做前后对比。不提供这个变量时只检查新版和后备渲染路径。不会加载生产API或调用模型。

主要修改源文件：`graphics/visualMeshes.ts`、`characters.ts`、`furniture.ts`、`officeRenderer.ts`、`officeWorld.ts`，以及`components/Office.tsx`、`StudioWorkspace.tsx`与对应样式。
